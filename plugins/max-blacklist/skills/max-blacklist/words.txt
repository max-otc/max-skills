# Custom word rules. Add a line, save. No restart, no code edit.
# Format:  phrase                     flag it, no suggested fix
#          phrase -> note             the arrow is OPTIONAL and it is yours to fill in
# The arrow separator must have SPACES around it, so a regex may contain a bare ->.
# Case-insensitive. Multi-word phrases work. Lines starting with # are ignored.
#
# EVERY WORD ENTRY IS BARE, as of 2026-08-14. The fix is your call, not the
# linter's, and an arrow took that call away: it funnelled every writer to one
# word. See the note at the head of [banned]. Only [pattern] keeps its arrows,
# where the right-hand side is the advice message shown on a hit.
#
# [banned]     words to replace with a plainer one
# [marketing]  sales adjectives with no meaning
# [phrasal]    two-word verbs that a single plain verb replaces
# [hedge]      filler that delays the sentence
# [address]    second person. Scored on its own key, second_person, so a wall of
#              "you" cannot drown out every other finding in the score.
# [pattern]    Python regexes, scored on their own key, pattern_hit. The report
#              names WHICH regex fired. A bad or slow regex warns and is skipped.
# [allow]      turn OFF any rule above, built-in or your own (phrase only, no arrow)
# [options]    tune a built-in rule. One  key = value  per line, see the block below.
#
# SCOPE. All of this applies to docs, READMEs, runbooks, specs, and prose inside
# code. It does NOT apply to agent instruction files (CLAUDE.md, AGENTS.md,
# SKILL.md), chat, commit messages, or rendered website prose. Those keep the
# Alexander voice, which uses em dashes and the direct "you" on purpose.

# ---------------------------------------------------------------------------
# THE COST OF THIS LIST, so you see it when you open the file.
#
# These are load-bearing CRX domain nouns. They name one specific thing and a doc
# often cannot avoid them. A margin doc cannot describe the prover without "guest",
# a hash without "digest", or the floor rule without "floored":
#     guest  digest  consent  rotation  rotations  anchor  anchors  mirror
#     firm  discriminator  idempotent  floored  floor  state  states  pinned
#
# Strong [allow] candidates, because they name a thing you cannot rename:
#     body  bodies      HTTP request body, response body, PR body, issue body
#     declaration(s)    Solidity and TypeScript declarations, in every code doc
#     state  states     state machine, state keeper, on-chain state
#     reach             bare reach also swallows the built-in phrasal "reach out"
#
# These collide with your own Alexander Voice section, which says "plain words
# first" and "name the failure plainly". They are exempt outside docs and code by
# the SCOPE rule above, and the Voice section was NOT edited:
#     plain  plainly  verbatim  stated  state  describe  describes  honestly  honest
#
# state and states will fire constantly on CRX docs (state machine, state keeper,
# on-chain state). They are the most likely [allow] candidates in this file.
# To turn any single rule off, copy it into [allow] at the bottom. Nothing else.
# ---------------------------------------------------------------------------

# The 's is the one ambiguous ending in English. It is a contraction in "it's ready"
# and a possessive in "the token's mark". Counting both gave 217 contraction hits on
# the contracts repo. Only 4 were contractions. The rest were possessives: account's,
# core's, token's, guest's, proof's, maker's, caller's. So the possessive is off here.
#
#
# Every key below takes flag or allow. flag is upstream behaviour and is the default
# when the key is absent or this file is absent. Each one was set to allow because a
# measured run on the contracts repo showed the rule charging for something no writer
# may rewrite. Set any key back to flag to see the old numbers.
#
#   possessive             the possessive 's is not a contraction. it's, that's,
#                          there's, let's still are, and so is every -'t -'re -'ve
#                          -'ll -'d -'m.                        217 hits -> 4
#   identifier_apostrophe  delegatecall'd and keccak'd hang an apostrophe on a code
#                          identifier. Not a verb, not a contraction.   10 hits -> 0
#   code_token             a version pin, a target triple, a hex address, a snake_case
#                          or camelCase name, and a numeric range are code. EIP-712
#                          and ERC-20 never flag.
#   markdown_structure     a table row is not one 40-word sentence, an empty cell drawn
#                          as a dash is not an em dash, eight bullets are not one
#                          paragraph, and an indented block of shell is not prose.
#   partial_token          report byte-for-byte, never the fragment byte-for. A rewrite
#                          driven by the fragment corrupts the word.
#
# EVERY STRUCTURAL EXEMPTION IS OFF. All three are built, all three are switches,
# and all three read flag. What stays ON is the name whitelist in
# [compound-allow], and the five false-positive fixes above: possessive,
# identifier_apostrophe, code_token, markdown_structure, partial_token. Those
# five charge for something no writer may rewrite. Nothing below does.
#
#   module_tag             "oracle-registry: zero pairId" at the head of a string
#                          literal. Built and switched OFF on your ruling, which
#                          is right: an error string is USER-FACING TEXT. It
#                          reaches a human. A log namespace is not furniture the
#                          way a file path or a version pin is. It is prose that
#                          happens to live in a string literal.           OFF
#   prefix_propernoun      pre-Cancun, post-Merge, non-EVM. A closed prefix on a
#                          proper name. OFF: pre-Cancun is jargon you might not
#                          want, so it is a real finding, not noise.       OFF
#   term_of_art            reads the [term-of-art] block at the end of this file.
#                          OFF, and the block is commented out too. Every entry in
#                          it is JARGON, which is prose, which you want to see.
#                          Two switches, so neither one can flip by accident. OFF
