# Custom word rules. Add a line, save. No restart, no code edit.
# Format:  phrase                     flag it, no suggested fix
#          phrase -> note             the arrow is OPTIONAL and it is yours to fill in
# The arrow separator must have SPACES around it, so a regex may contain a bare ->.
# Case-insensitive. Multi-word phrases work. Lines starting with # are ignored.
#
# EVERY WORD ENTRY IS BARE, as of 2026-08-14. The fix is your call, not the
# linter's, and an arrow took that call away: it funnelled every writer to one
# word. See the note at the head of [banned]. Only [pattern] keeps its arrows,
# where the right-hand side is the advice message shown on a hit.
#
# [banned]     words to replace with a plainer one
# [marketing]  sales adjectives with no meaning
# [phrasal]    two-word verbs that a single plain verb replaces
# [hedge]      filler that delays the sentence
# [address]    second person. Scored on its own key, second_person, so a wall of
#              "you" cannot drown out every other finding in the score.
# [pattern]    Python regexes, scored on their own key, pattern_hit. The report
#              names WHICH regex fired. A bad or slow regex warns and is skipped.
# [allow]      turn OFF any rule above, built-in or your own (phrase only, no arrow)
# [options]    tune a built-in rule. One  key = value  per line, see the block below.
#
# SCOPE. All of this applies to docs, READMEs, runbooks, specs, and prose inside
# code. It does NOT apply to agent instruction files (CLAUDE.md, AGENTS.md,
# SKILL.md), chat, commit messages, or rendered website prose. Those keep the
# Alexander voice, which uses em dashes and the direct "you" on purpose.

# ---------------------------------------------------------------------------
# THE COST OF THIS LIST, so you see it when you open the file.
#
# These are load-bearing CRX domain nouns. They name one specific thing and a doc
# often cannot avoid them. A margin doc cannot describe the prover without "guest",
# a hash without "digest", or the floor rule without "floored":
#     guest  digest  consent  rotation  rotations  anchor  anchors  mirror
#     firm  discriminator  idempotent  floored  floor  state  states  pinned
#
# Strong [allow] candidates, because they name a thing you cannot rename:
#     body  bodies      HTTP request body, response body, PR body, issue body
#     declaration(s)    Solidity and TypeScript declarations, in every code doc
#     state  states     state machine, state keeper, on-chain state
#     reach             bare reach also swallows the built-in phrasal "reach out"
#
# These collide with your own Alexander Voice section, which says "plain words
# first" and "name the failure plainly". They are exempt outside docs and code by
# the SCOPE rule above, and the Voice section was NOT edited:
#     plain  plainly  verbatim  stated  state  describe  describes  honestly  honest
#
# state and states will fire constantly on CRX docs (state machine, state keeper,
# on-chain state). They are the most likely [allow] candidates in this file.
# To turn any single rule off, copy it into [allow] at the bottom. Nothing else.
# ---------------------------------------------------------------------------

# The 's is the one ambiguous ending in English. It is a contraction in "it's ready"
# and a possessive in "the token's mark". Counting both gave 217 contraction hits on
# the contracts repo. Only 4 were contractions. The rest were possessives: account's,
# core's, token's, guest's, proof's, maker's, caller's. So the possessive is off here.
#
#
# Every key below takes flag or allow. flag is upstream behaviour and is the default
# when the key is absent or this file is absent. Each one was set to allow because a
# measured run on the contracts repo showed the rule charging for something no writer
# may rewrite. Set any key back to flag to see the old numbers.
#
#   possessive             the possessive 's is not a contraction. it's, that's,
#                          there's, let's still are, and so is every -'t -'re -'ve
#                          -'ll -'d -'m.                        217 hits -> 4
#   identifier_apostrophe  delegatecall'd and keccak'd hang an apostrophe on a code
#                          identifier. Not a verb, not a contraction.   10 hits -> 0
#   code_token             a version pin, a target triple, a hex address, a snake_case
#                          or camelCase name, and a numeric range are code. EIP-712
#                          and ERC-20 never flag.
#   markdown_structure     a table row is not one 40-word sentence, an empty cell drawn
#                          as a dash is not an em dash, eight bullets are not one
#                          paragraph, and an indented block of shell is not prose.
#   partial_token          report byte-for-byte, never the fragment byte-for. A rewrite
#                          driven by the fragment corrupts the word.
#
# EVERY STRUCTURAL EXEMPTION IS OFF. All three are built, all three are switches,
# and all three read flag. What stays ON is the name whitelist in
# [compound-allow], and the five false-positive fixes above: possessive,
# identifier_apostrophe, code_token, markdown_structure, partial_token. Those
# five charge for something no writer may rewrite. Nothing below does.
#
#   module_tag             "oracle-registry: zero pairId" at the head of a string
#                          literal. Built and switched OFF on your ruling, which
#                          is right: an error string is USER-FACING TEXT. It
#                          reaches a human. A log namespace is not furniture the
#                          way a file path or a version pin is. It is prose that
#                          happens to live in a string literal.           OFF
#   prefix_propernoun      pre-Cancun, post-Merge, non-EVM. A closed prefix on a
#                          proper name. OFF: pre-Cancun is jargon you might not
#                          want, so it is a real finding, not noise.       OFF
#   term_of_art            reads the [term-of-art] block at the end of this file.
#                          OFF, and the block is commented out too. Every entry in
#                          it is JARGON, which is prose, which you want to see.
#                          Two switches, so neither one can flip by accident. OFF

# against PUBLISHED lists rather than against this repo's own prose: the
# sentence structures in hardikpandya/stop-slop (references/structures.md),
# the layer-2 shapes in JMill/deslop, and the named structures on
# Wikipedia:Signs of AI writing. Fifteen ship. Five were measured and cut, and
# their rates sit at the end of this block so nobody proposes them again.
#
# THESE FIFTEEN SIT LAST, same reason rules 15 to 33 do: every rule above
# claims its spans first, so nothing here can steal a count from anything
# there. ALL FIFTEEN ARE CASE-FORCED with (?-i:...), the same trap this file
# has now hit three times: the loader compiles every [pattern] with re.I, so a
# bare [a-z] matches CAPS too, the span claim then eats an acronym, and the
# all-capitals rule silently loses the hit.
#
# READ THE COUNTS BEFORE READING THE RULES. Most of these score ZERO on the
# CRX corpus, and that is the finding rather than a defect. These shapes belong
# to essay, blog and landing-page prose, which is the half of the writing this
# repo's own corpus cannot exercise. A zero-hit rule carries a zero false-
# positive rate, which is the bar this file ships against; where a rule DID
# fire on CRX prose the count is stated and the innocent rate with it.
#
# Rule 34, FALSE AGENCY, the one stop-slop names and nothing here caught. An
# abstract noun is given a human verb, so the sentence never names who acted:
# "a complaint becomes a fix", "the decision emerges", "the culture shifts",
# "the market rewards". The first draft matched ANY noun and scored 232 hits at
# 10 in 12 innocent, because a router, a fold and a keeper genuinely do decide:
# machine agency is real agency and must not be charged. The shipped rule holds
# a CLOSED list of abstract subjects, which is the only form that separates the
# tell from the fact. 0 hits on the contracts corpus, 2 on the wider one, both
# of them the literal example sentence quoted in a note.
(?-i:\b(?:[Tt]he|[Aa]n?) (?:complaint|decision|culture|conversation|dialogue|discourse|narrative|story|journey|landscape|ecosystem|experience|relationship|trend|momentum|sentiment|market|data|insight|idea|truth|bet|process|outcome|community|industry|technology) (?:becomes|become|emerges|emerge|shifts|shift|evolves|evolve|rewards|reward|tells us|wants|knows|decides|chooses|demands|remembers|forgets|speaks|learns|teaches|understands|believes|feels|cares|lives or dies)\b) -> false agency: name the person who acted
# Rule 35, the faceless source. "research shows", "the data tells us",
# "experts say". deslop's provenance test in one line: a claim with no name on
# it cannot be checked. 2 hits, both "the data suggests", 0 innocent.
(?-i:\b(?:research|studies|the research|the data|the evidence|experts|science|history) (?:shows|show|tells us|suggests|suggest|says|say|proves|prove|reveals|reveal)\b) -> name the source and the affiliation
# Rule 36, the throat-clearing opener. "Here's the thing", "Here's what I
# mean", "Here is why that matters". The sentence announces a point instead of
# making it. 1 hit on the contracts corpus, 4 on the wider one, 0 innocent.
(?-i:\bHere(?:'s| is) (?:the|a|an|what|why|how|where|another|my|your)\b) -> throat-clearing: state the point
# Rule 37, the contracted antithesis. Rule 11 carries "is not X. It is Y" and
# was measured at 0 hits for the CONTRACTED form in 2026-08. The form occurs
# now: 1 hit, 0 innocent. The two partition, rule 11 cannot reach an apostrophe.
(?-i:\b(?:isn't|aren't|wasn't|weren't) [a-z][a-z ,'()]{0,60}[.,;] [Ii]t'?s\b) -> antithesis: drop the setup, state the fact
# Rule 38, the reframe on a named noun. "The question isn't X. It's Y", "The
# answer is not speed", "The problem isn't the code". A misdirection that
# spends a clause denying a question nobody asked. 1 hit, 0 innocent.
(?-i:\b[Tt]he (?:question|answer|problem|issue|point|goal|risk|truth) (?:isn't|is not)\b) -> reframe: name the thing directly
# Rule 39, dramatic fragmentation. "That's it. That's the whole rule." "Let
# that sink in." Performative simplicity: the fragment carries no fact the
# sentence before it did not. 0 hits.
(?-i:\bThat'?s it\b|\bThat'?s the [a-z]+\.|\bLet that sink in\b) -> fragment drama: write the complete sentence
# Rule 40, the narrator at a distance. "This is why", "This happens because",
# "People tend to", "What if". The writer floats above the scene and lectures
# rather than naming what happened. Rule 17 carries the pointer restatement on
# This; this carries the causal lecture. 0 hits.
(?m)(?-i:(?:^|(?<=\. ))(?:This is why|This happens because|People tend to|Nobody designed|What if )) -> narrator distance: put the reader in the room
# Rule 41, the transformation arc. "stops being a hedge and starts being a
# bet". The thing did not transform, somebody changed it. The bare "stops
# being" was tested and left out: 25 hits at 5 in 10 innocent, because a row
# really does stop being eligible. Only the full arc ships. 1 hit, 0 innocent.
(?-i:\bstops? being [a-z]+(?: [a-z]+){0,2} and starts? being\b) -> false transformation: name who changed it
# Rule 42, importance announced instead of shown. "The implications are

# calls it the vague declarative: a sentence that says a thing matters and

(?-i:\b[Tt]he (?:implications|stakes|consequences|reasons|risks|results) are (?:significant|structural|real|high|clear|profound|staggering)\b) -> name the specific thing, not its importance

# Rule 49, the summative closer. "All in all", "the key takeaway is", "and
# that's why it matters". A last paragraph that summarises instead of ending.
# The literal forms are in the [banned] block above and the literal rules claim
# them first; what this adds is the frame around a word the list cannot hold.
# The bare "The point is" is NOT here: it was measured in 2026-08 at 25 hits
# and 6 in 10 innocent, a label a writer meant, and it stays cut. 0 hits.

# Rule 50, uncited authority, slopless's own name for it. "experts agree",
# "studies show", "widely accepted". Rule 35 carries the singular sources
# (research, the data, science); this carries the plural ones and the passive
# consensus frame, and the two partition: on both corpora they share zero
# spans. deslop's provenance test again, and Wikipedia's AIVAGUE. 0 hits.

# stop-slop's lazy-extremes entry names the same habit. 0 hits on the contracts
